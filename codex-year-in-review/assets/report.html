How this was counted

Counts come from local active and archived Codex logs from the selected sources. Deleted logs, devices whose logs were omitted, and cloud-only usage may be missing. Overlapping logs are merged by session ID and duplicate events are counted once. Active days include recorded turn starts, tool calls, or token usage. Each chat or subagent session is counted once if it had activity in the window.

Turn starts include recorded Codex turns across primary and subagent sessions. Tool calls count recorded invocations across primary and subagent sessions. Tokens use recorded per-call usage, skipping repeated cumulative snapshots within a log. Cached input is part of input. Reasoning tokens are reported separately and can overlap output. These counts measure recorded activity. Billing and plan limits are tracked separately.
